# Site content

The website at https://tally.0xo.in (landing page, `/docs` and `/verify`) is
built from a private repository, `Tally-Network/tally-site`, because it uses
licensed template code that may not be redistributed. Everything the site
states lives here, in public:

| Path | What it is |
|:---|:---|
| `content/docs/` | The documentation pages (MDX), rendered at `/docs` |
| `content/generated/facts.json` | Every figure the landing page shows, generated from this repository |
| `content/claims/` | Each statement of fact on the site and the repository file that backs it |
| `CLAIMS.md` | The readable list of those claims, generated by the claims check |
| `scripts/gen-facts.mts` | Builds `facts.json` (`pnpm site:facts` from the repository root) |
| `scripts/check-claims.mjs` | The claims check |
| `scripts/check-site.mjs` | The link and verbatim-statement crawler, run against the live site |

The `/verify` page runs `verify/core.ts` from this repository in the browser,
the same module as `tally verify`.

## How the site uses this repository

The site build clones this repository (the `main` branch) and reads the docs,
`facts.json`, the claims and the files the claims cite from that clone. It
runs `scripts/check-claims.mjs --site <application>` before every build, so a
claim that no longer matches its source, or no longer appears on its page,
fails the deployment.

When the scheduled evidence refresh publishes a new round, it commits the new
`facts.json` here and calls the site's deploy hook; the site rebuilds from the
new commit.

## Checks you can run here

```bash
pnpm install
pnpm site:facts                                   # regenerate facts.json
node site/scripts/check-claims.mjs                # facts, sources, docs claims, phrasing
node site/scripts/check-site.mjs https://tally.0xo.in --external
```

Without the application, the claims check cannot see the landing page's text,
so it checks everything else and says how much it skipped.
